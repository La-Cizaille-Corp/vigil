Importer un SBOM

Un nouvel import du même projet remplace ses actifs : les actifs inchangés gardent leur historique de suivi. Les nouveaux actifs sont suivis sur les 120 derniers jours, comme un ajout manuel.

Importer un tableau (CSV)

Première ligne : noms des colonnes. Seule name (ou nom) est obligatoire ; colonnes reconnues : version, kind (type), criticality (criticité), owner (responsable), project (projet), purl, ecosystem, cpe, cpe_mode, cpe_from, track_since, notes, tags (étiquettes, séparées par des virgules). Les types et criticités s'écrivent comme dans l'interface (« Produit », « Haute »…) ou par leur code. Le plus simple : partir d'un export de l'inventaire. Le fichier entier est refusé à la moindre ligne invalide ; les lignes identiques à un actif existant sont ignorées.
