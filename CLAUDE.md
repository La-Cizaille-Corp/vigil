# Consignes pour Claude

Lire et appliquer [CONTRIBUTING.md](CONTRIBUTING.md), en particulier :

- **« Réutiliser avant d'écrire »**, à chaque changement : chercher la fonction qui fait déjà la
  chose, l'étendre plutôt que d'en écrire une voisine, ne garder qu'une façon de faire, et dire
  dans la PR ce qui a été réutilisé, étendu ou remplacé.
- **« Revue des versions X.Y.0 »** : avant de taguer une version mineure ou majeure, une revue
  d'optimisation et de sécurité de tout le code ; aucun constat de sécurité non tranché à la sortie.
